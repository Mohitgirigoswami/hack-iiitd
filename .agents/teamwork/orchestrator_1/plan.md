# Orchestration Plan: KhetOS Cosmic Dark Redesign & Live Telegram Daemon

Implement Credentia-inspired cosmic obsidian design language, 3D perspective cyber grid, interactive cockpit frame, farm-gate laser scanner, tilted glowing cards, and live Telegram bot daemon for KhetOS (खेतOS), fulfilling all requirements R1-R5 and acceptance criteria.

## Strategy & Pattern
- Pattern: Project Pattern (Top-level Project Orchestrator)
- Phase 0: Survey codebase with 3 parallel Explorers

  - Explorer 2 (Backend & Telegram): Flask backend, models/SQLite schema, existing routes, Telegram bot infrastructure, APMC mandi data, Bolero pool.
  - Explorer 3 (Integrity, Builds & Fast-Gates): `npm run build`, Flask endpoints, demo fast-gates (Baljit Singh, Shree Ram Mill, Dr. Vivek Swaminathan), port status.
- Phase 1: Synthesize Survey into `PROJECT.md`, verify Feature Inventory.
- Phase 2: Dispatch Dual Track (Implementation & E2E Testing).
  - Implementation Milestones:
    * M1: Visual Theme, Cosmic Horizon & Laser Bar (R1)
    * M2: 3D Cockpit Preview & Running Ticker Marquees (R2)
    * M3: Farm-Gate Quality Scanner Laser Animation (R3)
    * M4: 3D Glowing Portals & Glassmorphic Consoles (R4)
    * M5: Live Telegram Bot Daemon & Location Geo-Sync (R5)
    * M6: Final Verification & Acceptance Gate (pass 100% E2E tests + zero regressions)
- Phase 3: Gate each milestone with strict verification (Explorer -> Worker -> 2 Reviewers -> 2 Challengers -> Forensic Auditor).
- Phase 4: Final acceptance check and report back to Sentinel.
